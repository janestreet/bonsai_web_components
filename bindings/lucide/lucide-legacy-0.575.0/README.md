# Lucide legacy icons - 0.575.0

Icons that upstream Lucide removed but that we keep providing for compatibility.
Icons in the pinned Lucide/Lucide-lab releases always take precedence over this
directory, so if upstream ever re-adds a name, the upstream version wins.

The `LICENSE` file in this directory is the Lucide license (ISC, with portions from
Feather under MIT) as of `0.575.0`, the license these icons were distributed under.

Don't add new icons here; use `../custom/` for icons that never came from Lucide.
